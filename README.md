# 🍓 Styleberries

Веб-платформа интернет-магазина (кроссовки, обувь, одежда для женщин и мужчин) с UX-логикой маркетплейса: каталог с фасетными фильтрами, карточки товаров с вариантами, корзина, промокоды, отзывы, личный кабинет и полноценная админ-панель.

## Стек

| Слой | Технология |
|---|---|
| Фреймворк | Next.js 15 (App Router, Server Components + Server Actions) |
| Язык | TypeScript (strict) |
| Стили | Tailwind CSS |
| БД / ORM | SQLite (dev) / PostgreSQL (prod) через Prisma |
| Аутентификация | JWT-сессии в httpOnly cookie (jose + bcryptjs) |
| Валидация | Zod |
| Email | Nodemailer (console-транспорт для dev, SMTP для prod) |

## Быстрый старт

```bash
cp .env.example .env
npm install
npm run db:push     # создать SQLite-базу по схеме
npm run db:seed     # демо-данные: товары, пользователи, промокоды
npm run dev         # http://localhost:3000
```

### Демо-доступы

| Роль | Email | Пароль |
|---|---|---|
| Администратор | `admin@styleberries.example` | `admin123` |
| Покупатель | `customer@example.com` | `customer123` |

### Демо-промокоды

- `BERRY10` — скидка 10% без ограничений
- `SUMMER500` — −500 ₽ при заказе от 3 000 ₽ (лимит 100 использований)
- `VIP20` — −20% при заказе от 10 000 ₽ (лимит 20)

## Возможности

**Витрина**
- Главная: hero-баннер, категории, хиты продаж, скидки, новинки
- Каталог: поиск, сортировка (популярность / цена / новизна / скидка / рейтинг), фильтры по размеру, цвету, цене и наличию, пагинация
- Карточка товара: галерея, выбор цвета и размера с учётом остатков, скидки, отзывы с рейтингом, похожие товары
- Корзина: работает для гостей (cookie) и пользователей, лимит по остаткам
- Оформление: доставка курьером / в пункт выдачи (бесплатно от 5 000 ₽ курьером), промокоды с живым пересчётом, оплата через mock-шлюз (интерфейс для ЮKassa/Stripe готов)
- Личный кабинет: доставки с прогрессом, просмотренные товары, заказы с историей статусов, профиль; избранное; нижняя навигация как у маркетплейсов

**Админка** (`/admin`)
- Дашборд: выручка, заказы, товары с низким остатком
- Товары: создание/редактирование, цены и скидки, изображения, варианты (размер × цвет) и остатки
- Заказы: фильтр по статусу, смена статусов по state machine (NEW → PAID → PROCESSING → SHIPPED → DELIVERED, отмена с возвратом остатков)
- Промокоды: процентные и фиксированные, минимальная сумма, лимиты, срок действия, вкл/выкл

**Telegram Mini App**
- Магазин работает внутри Telegram: бот открывает Mini App кнопкой меню или по `/start`
- Автовход по подписанным `initData` Telegram — без регистрации и паролей
- Уведомления о заказе и смене статуса сообщением от бота (плюс дублирование на email)
- Автонастройка бота одной командой: `npm run telegram:setup` (см. [docs/TELEGRAM.md](docs/TELEGRAM.md))

**Системное**
- Email-уведомления о создании заказа и смене статуса (в dev пишутся в `.emails/`)
- Атомарное списание остатков при заказе (защита от гонок)
- Снимки позиций в заказе — смена цены не меняет историю
- Деньги в копейках (целые числа), без ошибок округления

## Скрипты

```bash
npm run dev        # dev-сервер
npm run build      # production-сборка
npm run start      # production-сервер
npm run typecheck  # проверка типов
npm run db:push    # применить схему Prisma
npm run db:seed    # демо-данные
npm run db:reset   # пересоздать БД + демо-данные
npm run smoke      # сквозной smoke-тест бизнес-логики (корзина → заказ → статусы)
npm run telegram:setup  # настроить Telegram-бота и Mini App (нужен TELEGRAM_BOT_TOKEN)
```
