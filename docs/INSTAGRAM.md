# Публикация товаров в Instagram

В админке на карточке товара есть кнопка **«Опубликовать в Instagram»**:
она выкладывает фото товара (одно или карусель до 10 штук) с подписью —
название, цена, размеры и призыв «заказать — в Telegram-боте, ссылка в
шапке профиля». Работает через официальный Instagram API — аккаунту
ничего не грозит.

## Подключение (один раз)

Всё, что нужно получить — **один токен**. Он вставляется в админке:
**Настройки → Instagram**. ID аккаунта система определит сама, ничего
на сервере править не нужно.

### Шаг 1. Тип аккаунта — «Бизнес»

Приложение Instagram → профиль → **≡** → Настройки → раздел
**«Для профессионалов»** → переключиться на профессиональный аккаунт →
тип **«Бизнес»**. Бесплатно; предложения подключить Facebook можно
пропустить («Не сейчас»).

### Шаг 2. Приложение Meta

1. [developers.facebook.com](https://developers.facebook.com) — войти
   через Facebook (подойдёт любой личный аккаунт).
2. **My Apps → Create App** → сценарий **Other** → тип **Business** →
   имя любое (например, Styleberries) → создать.
3. В панели приложения: продукт **Instagram** → **Set up** →
   **API setup with Instagram login**.

### Шаг 3. Токен

В блоке **Generate access tokens**:

1. **Add account** — войти в Instagram-аккаунт магазина (не личный!).
2. **Generate token** — скопировать токен целиком (начинается с `IGAA`).

### Шаг 4. Вставить в админку

Магазин → **Админка → Настройки → Instagram** → вставить токен →
**Подключить**. Система проверит токен, покажет «Подключено: @аккаунт» —
и на карточках товаров появится кнопка публикации.

## Обновление токена

Токен живёт ~60 дней. Когда публикация перестанет работать с ошибкой
про токен — сгенерируйте новый (шаг 3) и вставьте в том же поле настроек.

## Ограничения Instagram API

- Аватарку, имя и описание профиля через API менять нельзя — только
  вручную в приложении.
- Публикуются фото JPEG/PNG по публичной ссылке; SVG-заглушки
  пропускаются автоматически.
- Лимит Instagram: до 100 публикаций через API за 24 часа.

## Запасной вариант: переменные окружения

Вместо настроек в админке можно задать на сервере `INSTAGRAM_USER_ID`
и `INSTAGRAM_ACCESS_TOKEN` — они используются, если в админке ничего
не подключено.
