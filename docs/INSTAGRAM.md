# Публикация товаров в Instagram

В админке на карточке товара есть кнопка **«Опубликовать в Instagram»**:
она выкладывает фото товара (одно или карусель до 10 штук) с подписью —
название, цена, размеры и призыв «заказать — в Telegram-боте, ссылка в
шапке профиля». Работает через официальный Instagram API, аккаунту ничего
не грозит.

Кнопка появляется автоматически, когда заполнены переменные окружения
`INSTAGRAM_USER_ID` и `INSTAGRAM_ACCESS_TOKEN`. Как их получить — ниже,
один раз, минут 15.

## Шаг 1. Переключите аккаунт на «Бизнес»

В приложении Instagram: **Настройки → Для профессионалов →
Переключиться на профессиональный аккаунт** → тип «Бизнес» (или «Автор»).
Это бесплатно и обязательно: API работает только с такими аккаунтами.

## Шаг 2. Создайте приложение Meta

1. Зайдите на [developers.facebook.com](https://developers.facebook.com)
   (вход через ваш аккаунт Facebook; если нет — создайте).
2. **My Apps → Create App** → тип **Business** → любое название
   (например, Styleberries).
3. В списке продуктов найдите **Instagram** → **Set up**.
4. Выберите **API setup with Instagram login**.

## Шаг 3. Подключите Instagram-аккаунт и получите токен

1. В разделе Instagram → **API setup with Instagram login** нажмите
   **Add account** и войдите в ваш Instagram-аккаунт магазина.
2. Там же нажмите **Generate token** напротив подключённого аккаунта —
   скопируйте **долгоживущий токен** (действует ~60 дней).
3. **ID аккаунта** показан рядом с ним (Instagram user ID, число вида
   `17841400000000000`).

## Шаг 4. Пропишите переменные на сервере

В файл `.env` на сервере (или в переменные окружения Vercel) добавьте:

```
INSTAGRAM_USER_ID="17841400000000000"
INSTAGRAM_ACCESS_TOKEN="IGAA..."
```

и перезапустите приложение. Кнопка появится на каждой карточке товара
в админке.

## Обновление токена

Токен живёт ~60 дней. Продлить (в любой момент до истечения):

```
curl "https://graph.instagram.com/refresh_access_token?grant_type=ig_refresh_token&access_token=ТЕКУЩИЙ_ТОКЕН"
```

Ответ содержит новый токен — замените его в `.env`. Если токен истёк,
просто сгенерируйте новый в приложении Meta (шаг 3).

## Ограничения Instagram API

- Аватарку, имя и описание профиля через API менять нельзя — только
  вручную в приложении (тексты и аватарки — в комплекте оформления).
- Публикуются фото JPEG/PNG по публичной ссылке; SVG-заглушки
  пропускаются автоматически.
- Лимит Instagram: до 100 публикаций через API за 24 часа.
